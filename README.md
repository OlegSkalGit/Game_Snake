# 🐍 3D Snake Adventure — Кампанія (18 Світів × 5 Етапів + Збереження Прогресу)

Повноцінна тривимірна динамічна гра «Змійка» на рушії **Ursina Engine (Panda3D)** із **системою збереження прогресу** (новий світ відкривається лише після проходження попереднього), 18 насиченими саундтреками, структурою по 5 підрівнів на кожен світ (90 етапів), текстурами поверхонь і змійки, оновленими супербонусами та AI опонентами.

---

## 🌟 Ключові особливості

- 💾 **Система збереження прогресу та відкриття рівнів ([`scripts/save_manager.py`](file:///d:/Projects/Antigravity/projects/Snake/scripts/save_manager.py))**:
  - На старті гри доступний лише **Світ 1**.
  - Кожен наступний світ відкривається **лише після повного проходження всіх 5 підрівнів попереднього світу**!
  - Прогрес відкритих світів та рекордний рахунок автоматично зберігаються у файл `save_data.json` і відновлюються при кожному наступному запуску гри.
  - У меню рівні позначаються кольорами та статусами: `[Доступно]`, `[Пройдено]`, `[Закрито]`.
- 🎵 **18 Поліфонічних Саундтреків (16-тактові композиції)**:
  - Кожен із 18 світів має власну композицію (фолк, арабський макам, амбієнт, синтвейв, техно, аутран, фанк, дарксинт тощо).
  - Кнопка `[M]` для швидкого вмикання / вимикання музики.
- 🏆 **18 Світів по 5 Підрівнів (90 Етапів)**:
  - Етапи 1–4 зі зростаючою складністю та Етап 5 (Бос-етап світу).
- 🎁 **Повна система бонусів та підсилювачів**:
  - 🧲 **Магніт** (10 с), ⚡ **Турбо** (+25% на 10 с), ❄️ **Сповільнення** (-25% на 10 с), ❤️ **+1 Життя**, 🍉 **+10 Їжі**, 🛡️ **Щит** (12 с), ⭐ **Золоте Яблуко**.
- ⚔️ **AI Противники полюють та їдять їжу й бонуси**.
- ✂️ **Бойова механіка відкушування хвоста (PvE Tail Severing)**:
  - Можна атакувати ворожих змійок у хвіст або бік, відкушуючи їхні сегменти, які розсипаються на смачний бонусний лут!
- ❤️ **Система 3 Життів на етапі**.

## 🎮 Керування

| Клавіша | Дія |
| :--- | :--- |
| `A` / `D` або `←` / `→` | Плавний розворот змійки (з динамічним нахилом тіла) |
| `SPACE` або `SHIFT` | Ручне Турбо-прискорення |
| `C` | Перемикання режимів камери (3-тя особа, Зверху, 1-ша особа) |
| `Коліщатко миші` / `+` / `-` | Зміна масштабу (Zoom In / Zoom Out) |
| `M` | Увімкнути / вимкнути фонову музику |
| `H` або `F1` | Відкрити / закрити Довідку |
| `ESC` або `P` | Пауза |
| `R` | Швидкий рестарт етапу |

---

## 🚀 Запуск гри

Двічі клацніть **`_START_.bat`** або виконайте у консолі:
```bash
python main.py
```
